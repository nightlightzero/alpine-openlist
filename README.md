# alpine-openlist
为alphine系统定制的一键openlist安装脚本
--------------------------------------------
全球一键安装脚本（github原仓库）：
'''
wget -qO- https://github.com/nightlightzero/alpine-openlist/blob/main/alpine-openlist.sh | ash
'''

国内一键安装脚本（ghproxy）:
'''
wget -qO- https://ghproxy.com/https://raw.githubusercontent.com/nightlightzero/alpine-openlist/main/alpine-openlist.sh | ash
'''
